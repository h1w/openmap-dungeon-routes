# OpenMap Dungeon Routes

Маршруты ForeverDungeonRoutes внутри карт подземелий OpenMap для WoW Forever (Interface 16001).

## Зависимости и установка

- Обязательны [OpenMap](https://github.com/openmap-world/openmap) и [ForeverDungeonRoutes](https://github.com/Checkov23/ForeverDungeonRoutes).
- DungeonJournal (папка `ForeverDungeonJournal`) и AzerothCompendium необязательны. Портрет каждого босса ищется по порядку: API Forever → DungeonJournal → AzerothCompendium → череп. Один неудачный поиск не отключает найденные портреты остальных боссов.
- Скопируй папку `OpenMapDungeonRoutes` в `Interface/AddOns/`, затем `/reload`. Если клиент не обнаружил новую папку, перезапусти игру.
- GitHub «Download ZIP» содержит весь репозиторий: в AddOns нужно перенести только вложенную папку `OpenMapDungeonRoutes`, не корень репозитория.
- Проверяемые исходные версии: OpenMap v0.8.7, FDR 1.0.13, DungeonJournal 2.0.4, AzerothCompendium 1.0.11, клиент 1.60.1.70938.

## Использование

- Открой вход подземелья на OpenMap или `/omdr` для списка данжей и рейдов.
- На карте: выбор маршрута, переключатель линий, следование текущему этажу/комнате.
- «Боссы» скрывает только метки боссов на текущий просмотр. При повторном открытии карты или выборе другого данжа они снова включены; смена этажа и зума не сбрасывает выключение. «Маршруты» сохраняет выбранное состояние между открытиями.
- Все встроенные и пользовательские маршруты берутся из FDR; редактор и импорт доступны через `/fdr`.
- Клик по боссу переключает отметку прохождения в FDR; Alt-клик показывает его группе через FDR.
- Синие стрелки переключают этажи. Прогресс убийств обновляется событиями FDR.
- `/omdr pos` вызывает штатную диагностику FDR: реальные координаты, этаж, подзона и распознанная комната.

## Позиция и карты

Если клиент открывает точные координаты, карта показывает стрелку, никнейм и координаты 0–100. Иначе используется текущая комната: область подсвечивается, ромб и ник стоят у её центра без дополнительной пометки. Нижняя строка поясняет, что это область комнаты, а не точные координаты. Если неизвестна даже комната, позиция не отображается. Групповые подписи показывают комнаты участников с установленным FDR.

Интеграция использует этажи и координаты FDR внутри окна OpenMap. Обычные карты берутся из встроенного исправления локалей OpenMap (`MapTile`), рисованные карты новых данжей — из установленного FDR. Некроситет и Наксрамас используют изображения Compendium при его наличии; без него — игровые minimap-части из FDR с той же проекцией маршрутов. Отсутствие необязательных аддонов не блокирует запуск. Изображения не копируются и не перепаковываются. Отдельная карта FDR автоматически не открывается при входе; `/fdr` остаётся доступен, исходная настройка восстанавливается при выходе/перезагрузке.

Blackmaw Hold не имеет готового маршрута в FDR 1.0.13. Там можно создать свой. Восемь новых маршрутов FDR приблизительны; интеграция не повышает точность исходных данных. При отсутствии модели босса показывается штатная иконка-череп, а не чужой портрет.

Портреты: native API перечисляет разделы журнала, подземелья и рейды, сопоставляя DungeonEncounterID с JournalEncounterID и именами в контексте конкретного данжа. При отсутствии данных берутся явные модели/иконки и aliases DungeonJournal, затем модели Compendium. Функция игрового API может существовать, но возвращать пустой журнал — это не ошибка. Данные и ресурсы необязательных аддонов читаются только во время игры.

## Совместимость
Доступ к внутреннему `OpenMapDungeonView` изолирован в `Host.lua`. Обновления OpenMap могут потребовать обновления адаптера. Никакие файлы OpenMap, FDR или Compendium на диске не изменяются. Отключение аддона и `/reload` возвращает исходные таблицы карт OpenMap.

## Удаление и неполадки

Отключи или удали только папку `OpenMapDungeonRoutes` и выполни `/reload`. Маршруты и прогресс остаются в FDR. При отсутствии портрета проверяются источники по указанному порядку; череп означает, что ни один источник не дал подходящих данных. При обновлении OpenMap проверь совместимость внутреннего dungeon-view. Об ошибках сообщай через GitHub Issues с версией клиента, версиями аддонов и скриншотом без личных данных.


## Проверка

```powershell
uv sync --locked
uv run python tests/check.py --addons "<game>/Interface/AddOns"
```

Сборка устанавливаемого архива без игровых ресурсов:

```powershell
uv run python tools/package.py
```

Архив появится в `dist/`. Python и uv нужны только для разработки/упаковки, игроку они не нужны. GitHub Actions проверяет синтаксис Lua 5.1 и сборку архива; интеграционные сценарии с установленными аддонами запускаются локально командой выше.

Проверяются Lua 5.1, реальные данные этажей/крыльев FDR, обрезка рисованных карт, выбор портрета из установленного провайдера, точная позиция, приблизительная комната и отсутствие метки на чужом этаже/данже.

Проверено в настоящем игровом интерфейсе: карты Мёртвых копей, Даларана, Забытых городов, Стратхольма и Наксрамаса; смена этажей; выбор живой/мёртвой стороны Стратхольма; портреты и линии; скрытие слоя при закрытии карты. Lua-проверка подтверждает наличие 729 используемых локальных ресурсов. В Даларане (инстанс 2959, «Ведьма и ворон», клиент 1.60.1.70938) вне боя `UnitPosition` не вернул координаты, `C_Map.GetPlayerMapPosition` вернул nil для всех 70 проверенных карт, HereBeDragons также не дал позиции. Миникарта дала радиус обзора, но не UiMapID или мировую привязку. Проверка ограничена этим инстансом и состоянием клиента; движения персонажа и меток живой группы не проверяли. Сценарии Lua отдельно проверяют выбор точной позиции/комнаты и изоляцию этажей.
